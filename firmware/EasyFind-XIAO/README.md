# EasyFind XIAO 自拍杆测试固件

目标：Seeed XIAO ESP32S3 Sense，8 MB Flash / 8 MB PSRAM。此固件替换录音程序，用于验证 EasyFind 已有的自拍杆协议；不使用板载摄像头、麦克风或 SD 卡。

## 使用

1. USB 给开发板供电。iPhone 打开“设置 → 蓝牙”，查找并配对 **EasyFind Remote**。
2. 打开实体 iPhone 上的 EasyFind，“功能 → 远程拍照”读取设备配置，设置 0–30 秒并保存。默认 3 秒。
3. 打开手机系统相机，短按开发板 **BOOT** 按钮，设备倒计时结束后发送一次音量增加键。倒计时期间再次短按取消。
4. 保存后，延时由开发板执行；退出 EasyFind 后仍应能使用系统相机拍照，需在手机上实测。
5. 长按 BOOT 至少 1 秒后松开，请求 EasyFind 找手机。需要 App 的蓝牙订阅；iOS 26 起首次允许系统闹钟并保存“允许响铃”，之后可在锁屏约 2 秒后响铃并从锁屏停止。旧系统使用通知权限。已在一台 iPhone 验证后台、锁屏、静音及重复触发；强制退出 App 后不保证可用。

不要在通电或复位时按住 BOOT，否则会进入下载模式。RST 是复位按钮，不是拍照按钮。相机必须已经打开；固件不会解锁手机或自动打开相机。未连接时按键不会排队，重连不会补拍。

设备只接受一个手机 BLE 连接，系统 HID 和该手机的 EasyFind 共用这个连接。改用另一台手机前先断开原手机。原录音程序暂时不可用；恢复后可继续使用。

## 构建

使用 PlatformIO Core，执行 `pio run`。版本固定为 Espressif32 7.0.1、NimBLE-Arduino 1.4.3。USB 上传端口以实际枚举结果为准。不要对不明设备或多个同型号设备使用自动上传。

主机协议测试：

```sh
clang++ -std=c++11 -Wall -Wextra -Werror -I include tests/protocol_test.cpp -o /tmp/easyfind-protocol-test
/tmp/easyfind-protocol-test
```

协议详见项目 `docs/selfie-stick-protocol-v0.1.md`。自定义服务与 App 相同，标准 HID 服务为 0x1812。配置写入要求加密，配对采用无输入输出的绑定模式；原型未限制为唯一持有者，不适合直接当量产安全方案。

## 串口诊断

115200 波特率，每条命令以换行结束。打开串口可能复位开发板。

| 命令 | 用途 |
| --- | --- |
| `STATUS` | 版本、存储、延时、连接、加密及订阅状态 |
| `FRAME 53460101070000` | 经协议处理器读取配置 |
| `FRAME 5346010234120105` | 经协议处理器保存 5 秒 |
| `PRESS_SHORT` | 调用短按逻辑；无 HID 连接会拒绝 |
| `PRESS_LONG` | 调用找手机逻辑；无 App 订阅会拒绝 |
| `CANCEL` | 取消当前倒计时 |
| `REBOOT` | 重启开发板，用于检查配置持久化 |

`serial.reply` 仅验证板端报文与 Flash，不代表 BLE 已联调；`hid.volume_increment=sent` 仅表示发出按键，不代表照片成功保存。电量报告固定 100%，仅用于 USB 供电原型，不是测量值。

## 恢复

烧录前保存了原板完整 8 MB Flash，并与原厂 ZIP 的 bootloader、分区表、boot_app0 和应用镜像逐字节核对一致。完整备份可能包含设备私有信息，请只留在本机。

后续恢复应使用对应备份或原厂四个镜像的偏移 0x0、0x8000、0xe000、0x10000。先核对目标端口和 SHA256，再执行恢复；不需要对 SD 卡格式化。恢复后手机可能缓存旧 GATT 服务，必要时在系统蓝牙“忽略此设备”并重新配对。
